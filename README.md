# WallRaven

build a windows tray app to pull a wallpaper from wallhaven.cc and set it as the windows wallpaper. It needs all the same filters and searches as the main site (e.g. I want to be able to say only 4k and above, only 16:9, add a search term, filter out sketchy/nsfw (or only show those) etc. It needs to be as good as an "official" app. It needs to run in the windows tray and consume little to no resources. It can cache the images locally with a slider to determine how much storage is used locally before it deletes the oldest wallpapers. Include options for how often to cycle wallpaper, which colours to use, etc.
